# Techcadia

**Techcadia** is an educational game designed to immerse players in the world of technology. Through interactive challenges and scenarios, players explore the fundamentals of:

- **Coding**  
- **Information Technology (IT)**  
- **Programming**  
- **Cybersecurity**

Whether you're a student eager to learn or an educator seeking engaging teaching tools, Techcadia offers a gamified approach to mastering essential tech skills.

## Features

- **Interactive Gameplay**: Dive into scenarios that simulate real-world tech challenges.
- **Progressive Learning**: Start with foundational concepts and advance to complex topics.
- **Diverse Topics**: Covering areas from basic coding to advanced cybersecurity techniques.
- **Engaging Missions**: Solve puzzles and complete tasks that reinforce learning objectives.

## Installation

To get started with Techcadia:

1. Clone the repository:
   ```bash
   git clone https://github.com/clarencescott/Techcadia.git
   cd Techcadia
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the game:
   ```bash
   npm start
   ```

*(Note: Ensure you have Node.js and npm installed on your system.)*

## Technologies Used

- **Frontend**: React.js
- **Backend**: Node.js
- **Game Engine**: Phaser.js
- **Database**: Firebase (for user data and progress tracking)

## Educational Objectives

Techcadia aligns with key concepts from:

- **Computer Science Education Standards**: Introducing logical thinking and problem-solving skills.
- **Cybersecurity Fundamentals**: Understanding threats, defenses, and ethical considerations.
- **Programming Logic**: Grasping the basics of algorithms and coding structures.
